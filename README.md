## How to Use

You can deploy these skills inside Claude using three primary methods depending on your workflow:

### Method 1: The Desktop/Custom Skills Platform
1. Prepare the File: Choose the skill you want from this repository.
2. Rename: Save the file content exactly as SKILL.md (or bundle it inside a .zip file containing SKILL.md).
3. Upload: Go to your Claude Custom Skills panel and drag-and-drop the file into the importer area. The system will automatically parse the YAML frontmatter.

### Method 2: Project Knowledge base (Claude Pro)
1. Open your specific Claude Project.
2. Upload the desired skill file (e.g., aether-windows.md or apex-up.md) directly into the Project Knowledge sidebar.
3. Claude will silently maintain this system prompt protocol across all subsequent chats within that project.

### Method 3: Direct Prompt Injection
1. Copy the entire markdown text of your chosen skill.
2. Paste it as the very first message in a new chat conversation.
3. Instruct Claude: "Execute under this system protocol from now on."
